# Feature requests

FRs arrive from consumer apps (primarily HyperStruct) as markdown files in this
folder. When every item in a document has shipped, the document moves to
[`archive/`](archive/). A living document (one still accruing new sections)
stays here until it goes quiet.

## Open

- [`hyperstruct-collapsible-header.md`](hyperstruct-collapsible-header.md) — **FR-55-01, FR-55-02**, from HyperStruct's
  validation results as an accordion (5.6.1): a meta slot (badges) in an accordion panel's header; a collapsible card
  whose whole header toggles it (opt-in), interactive descendants keeping their own click.
