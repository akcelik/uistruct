# Feature requests

FRs arrive from consumer apps (primarily HyperStruct) as markdown files in this
folder. When every item in a document has shipped, the document moves to
[`archive/`](archive/). A living document (one still accruing new sections)
stays here until it goes quiet.

  itself meanwhile).

  surface carried the grouping and severity carried the weight. The one item

- [**`archive/icon-pen.md`**](archive/icon-pen.md) — FR-68-01, the pen a glyph
  is drawn with. Shipped in **v7.2.0** and finished in **v7.2.1**, which is in
  the document: 7.2.0 claimed every icon was on the pen and five were not,
  because the cleanup and the gate shared an assumption and so agreed with each
  other.

Two things from FR-67 are worth carrying into whatever is filed next, and both
are about the gate rather than the ask. **A gate has to measure what an eye
would see, not that two values differ** — FR-67-06 was accepted on
`surfaces.size > 1`, which passes on a 1.00:1 difference as happily as on a
1.17:1 one. And **a component the visual suite does not hold is a component
nothing contradicts** — the suite had no alert, no card and no hero, so neither
the 7.0.0 claim nor the first 7.4.0 draft ever met a picture that disagreed.

Everything HyperStruct has filed is in [`archive/`](archive/)
with the version that closed it, and
[`hyperstruct-hand-built-audit.md`](hyperstruct-hand-built-audit.md) is the
index of the 2026-09 full audit (all 45 asks shipped). The last two closed in
**v6.1.0** (a resizable grid's widths) and **v6.2.0** (one control height per
size); the height document names the one piece deliberately left undone, an
icon that resizes with the control it sits in, and why.

The one item that had been deferred — **D1** of the datagrid audit (the
component's API surface: 52 inputs, 6 outputs, 3 805 lines) — has shipped:
the inputs became feature objects (`[selection]`, `[paging]`, `[pane]`,
`[virtual]`, `[grouping]`, `[filtering]`, `[state]`) in **v5.30.0**, the
component split into four files in **v5.31.0**, the codemod landed in
**v5.32.0**, and **v6.0.0** removed the flat inputs (54 inputs → 33).
